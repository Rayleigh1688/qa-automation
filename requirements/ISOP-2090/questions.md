## 问题详情

<a id="q-02"></a>
### Q-02：活动改为周结或设上限，条款也跟着改吗？

**场景：** 后台可选择日、周、月结算，也可以配置返利上限。

**问题点：** Lark活动条款却固定写“日结次日派发、无上限”，与部分可选配置不一致。

**需要确认：** 本次活动只允许与固定条款一致的配置，还是条款随实际配置变化？若随配置变化，请补日、周、月及有无上限的对应文字。

<a id="q-03"></a>
### Q-03：多类返利到账，账变记一笔还是多笔？

**场景：** 同一会员在同一周期有两个游戏类型达到返利条件，分别得到返利。

**问题点：** 旧正文要求合并为一笔账变；新评论改成各类型独立计算，但没有说明是否也改变到账记录。

**需要确认：** 是否继续合并一笔账变？若改为分笔，请说明每笔与返利明细如何对应。确认前保留旧正文的合并规则作为已有依据。

<a id="q-04"></a>
### Q-04：周期内升级VIP，返利按哪个等级算？

**场景：** 玩家投注时为VIP1，结算前升级为VIP2；两个等级的返利比例不同。

**问题点：** 已有VIP费率表，但未明确采用哪个时点的等级。

**需要确认：** 按每笔投注时的VIP等级、结算时的等级，还是其他时点计算？

<a id="q-05"></a>
### Q-05：跨日、周、月的投注分别计入哪一期？

**场景：** 一笔投注发生在周期结束前，结算在下一周期；周期边界还可能跨周或跨月。

**问题点：** 正文已有周一派上周、每月1日派上月的安排，统计使用的时区、起止时刻和注单归属时间仍不完整。

**需要确认：** 请补日、周、月各自的时区与起止时刻，并说明按投注时间还是结算时间归属周期。

<a id="q-06"></a>
### Q-06：很小的返利是否派发，小数怎样处理？

**场景：** 示例：按比例计算得到0.005，或多个类型分别算出带多位小数的返利。

**问题点：** 本需求尚未明确最低派发金额，以及各类型计算和汇总时的小数处理顺序。

**需要确认：** 最低多少才派发？每项和合计分别保留几位、怎样舍入、先舍入还是先汇总？不能直接套用2032的最低0.01规则。

<a id="q-07"></a>
### Q-07：周期内修改返利配置，什么时候生效？

**场景：** 一个结算周期尚未结束，后台修改了返利比例、门槛或上限。

**问题点：** 未明确本周期已发生的投注继续用旧配置，还是按新配置重新计算。

**需要确认：** 修改从哪个时点生效？已发生投注和已结算周期分别怎样处理？

<a id="q-08"></a>
### Q-08：旧配置里的0，上线后怎样处理？

**场景：** 旧正文把上限0解释为停发，新产品决定把上限0解释为不限；历史配置可能已经保存了0。

**问题点：** 新规则已明确，旧配置是否保留原意或迁移还没有说明。

**需要确认：** 上线时这些旧配置怎样转换或保留？请说明是否需要人工确认，以及如何避免已有活动意外开始派发。

<a id="q-09"></a>
### Q-09：派发失败后怎样补发，如何避免重复到账？

**场景：** 周期返利派发中途失败，后续再次执行同一批次。

**问题点：** 失败后由谁触发补发、哪些记录需要重试，以及如何识别已经到账的返利尚未明确。

**需要确认：** 请产品确认补发流程；开发补充可查询的批次和记录标识、成功/失败状态，以及防止同一笔返利重复到账的依据。

<a id="q-10"></a>
### Q-10：只有一类触发封顶，汇总报表怎样标记？

**场景：** 同一会员的A类型返利达到上限，B类型没有达到上限，后台汇总展示两类返利。

**问题点：** 改为类型独立上限后，主表的封顶标记怎样表达尚未明确。

**需要确认：** 汇总行何时显示封顶标记？请同时说明如何从汇总行查看触发封顶的类型明细。

## 已有答案

<a id="q-01"></a>
### Q-01：返利按类型独立计算，0上限表示不限

**已确认：** 每个游戏类型或指定组独立计算；净输严格大于门槛才符合条件，门槛0表示有净输即发；上限0表示不限；盈利类型不抵销其他类型的净输。

**答复来源：** 产品评论17355（2026-09-16）明确替代旧正文中的全站门槛和0停发条款。本地已同步，远端正文仍待维护；评论未改变的共用流水倍数、周期和派发时间继续保留。
