## 问题详情

<a id="q-01"></a>
### Q-01：免费旋转弹窗什么时候出现？

**场景：** 系统向会员派发免费旋转奖励，会员可能在线，也可能之后才登录。

**问题点：** 已读文档主要说明现金金额动效，没有明确免费旋转专用的触发事件和显示时点。

**需要确认：** 什么事件会触发免费旋转弹窗？在线派发和之后登录分别如何处理？已有返利需求的登录通知规则是否适用，需要单独说明。

<a id="q-03"></a>
### Q-03：弹窗要显示哪些奖励信息？

**场景：** 会员收到一份指定游戏的免费旋转奖励。

**问题点：** 免费旋转有次数、适用游戏和有效期，不能直接用现金金额代替；现有可读文本尚未给出专用展示规则。

**需要确认：** 次数、游戏、有效期分别是否显示，如何显示？请给出免费旋转弹窗的设计位置或示例文案。

<a id="q-04"></a>
### Q-04：点弹窗按钮后，要发生什么？

**场景：** 会员看到免费旋转派发弹窗，准备点击主按钮或关闭弹窗。

**问题点：** 主按钮是领取奖励还是直接进入游戏、关闭后奖励和通知处于什么状态，尚未明确。

**需要确认：** 请说明每个按钮的文字、点击后的页面和奖励状态，以及关闭弹窗后的处理方式。

<a id="q-05"></a>
### Q-05：连续收到两笔奖励，弹窗怎么显示？

**场景：** 第一份免费旋转奖励的弹窗尚未处理，又收到第二份奖励。

**问题点：** 现有用例需要核对多笔通知，但尚未明确逐个显示、合并显示或其他处理方式。

**需要确认：** 两份奖励分别如何展示和处理？若沿用现有通知规则，请给出对应规则。

<a id="q-02"></a>
### Q-02：这次弹窗与一期、2120分别做什么？

**场景：** 本单和ISOP-2120都引用《金额动效弹窗》，项目中也已有一期弹窗与通知规则。

**问题点：** 两单没有在已读文本中分别列出交付内容，哪些复用、哪些新增还不清楚。

**需要确认：** 请列出本单复用的一期内容、本单新增内容，以及留给2120的内容；哪些已有通知规则可直接沿用也请注明。
