<a id="c01"></a>
### ISOP-2124-C01：责任博彩声明不可跳过

**前置条件：**

未登录及已登录专用会员；分别从启动页和返回首页进入。

**操作步骤：**

1. 点击 LEAVE；尝试继续进入首页。
2. 重新进入声明，点击 I AGREE ALL；再次进入首页。

**预期结果：**

1. 不同意时停留声明，不能进入首页；同意后继续。
2. 每次进入首页重新确认声明；Safari 不再提示选项不能取消此确认。

**待确认：**

<a id="c02"></a>
### ISOP-2124-C02：Safari弹窗指引与不再提示

**前置条件：**

iOS Safari 的新站点会话；保留可恢复的提示设置。

**操作步骤：**

1. 打开 Filplay，进入弹窗说明并点击 VIEW INSTRUCTIONS。
2. 返回后点击 GOT IT；重新进入，勾选 Don’t show this again 再关闭。
3. 再次进入站点。

**预期结果：**

1. 出现 Enable Pop-ups For Better Experience，教学可打开，GOT IT 可关闭。
2. 勾选后该说明不再显示；未将责任博彩声明一并跳过。

**待确认：**

—

<a id="c03"></a>
### ISOP-2124-C03：验证码登录区分新号与旧号

**前置条件：**

一组未注册测试手机号、一组已注册手机号；可接收测试验证码；邀请链接有有效邀请码组及无邀请参数组。

**操作步骤：**

1. 打开 Phone，核默认页签。
2. 分别输入两组手机号、有效6位验证码，勾选条款后提交；有邀请参数时检查推荐码自动带入。
3. 退出后再次用已注册手机号登录，核账号身份。

**预期结果：**

1. 默认 ONE-TIME CODE，区号 +63，手机号10位。
2. 新号验证后创建账号并登录；旧号登录原账号，不重复创建。
3. 邀请参数带入推荐码；无邀请参数时推荐码可选填。

**待确认：**

—

<a id="c04"></a>
### ISOP-2124-C04：验证码倒计时与表单拒绝

**前置条件：**

未登录；准备9位／11位手机号、非数字手机号、不满6位验证码及服务端判定无效的验证码。

**操作步骤：**

1. 使用格式错误的手机号获取验证码或提交。
2. 有效手机号点击 GET CODE，观察45秒倒计时及结束后的再次获取。
3. 分别使用错误验证码、未勾选条款提交。

**预期结果：**

1. 错误格式或未勾条款有提示，不能成功登录或创建账号。
2. 获取验证码后按钮倒计时45秒，倒计时结束恢复可获取状态。
3. 无效验证码不能形成登录会话；不自行规定短信频控次数及过期秒数。

**待确认：**

—

<a id="c05"></a>
### ISOP-2124-C05：密码登录与条款校验

**前置条件：**

已绑定手机号且已设置登录密码的测试会员；准备正确、错误密码。

**操作步骤：**

1. 切换 PASSWORD；正确手机号和密码但不勾条款提交。
2. 勾选条款后分别提交错误和正确密码。
3. 登录后核本人身份与首页。

**预期结果：**

1. 未勾条款及错误凭据不能登录，不展示他人资料。
2. 正确凭据及条款通过后进入首页；不把登录成功当作资金或游戏准入通过。

**待确认：**

—

<a id="c06"></a>
### ISOP-2124-C06：忘记密码规则与重置

**前置条件：**

测试会员可接收验证码；新密码以本地别名引用，不写入报告。

**操作步骤：**

1. 打开 Forgot Password，依次填写手机号、验证码及新密码。
2. 逐组输入7位／8位／20位／21位、纯字母、纯数字及字母数字组合。
3. 有效验证码及8位或20位合规密码提交，分别核旧密码与新密码登录。

**预期结果：**

1. 8—20位且至少一个英文字母及一个数字才满足正文规则；规则清单实时提示，未达项红色✕。
2. 字段错误框红并在字段下显示原因；校验未通过不改变密码。
3. 成功重置后新密码可用、原密码失效；测试密码不出现在导出证据。

**待确认：**

—

### ISOP-2124-C07：首页广告随配置展示与跳转

<a id="c12"></a>
### ISOP-2124-C12：KYC与白名单游戏准入

**前置条件：**

未认证、审核中、已通过KYC三组会员；明确的白名单／非白名单域名；均未被后台禁玩。

**操作步骤：**

1. 未认证会员在非白名单域名启动游戏，分别点DO IT LATER及GO TO KYC VERIFY NOW。
2. 未认证会员在已确认白名单域名启动；审核中和已通过会员在非白名单域名启动。

**预期结果：**

1. 非白名单未认证出现游戏版KYC提示，稍后关闭、立即认证进入KYC。
2. §3白名单例外仅用于游戏；审核中与已通过可通过KYC这一项检查。
3. 仍须满足其他启动条件并验证实际游戏会话；不扩大到充值、提现或活动豁免。

**待确认：**
