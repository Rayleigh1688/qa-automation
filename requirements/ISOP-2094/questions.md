## 问题详情

<a id="q-01"></a>
### Q-01：哪些站点已经部署，可以开始验收？

**场景：** 准备分别验证产品站和工具站的地区访问限制。

**问题点：** 2026-09-09评论说明代码已合并，但当时测试站尚未重新发布；当前本地没有后续部署证据。

**需要核验：** 请给出需验收的域名清单、各站点已部署版本和对应发布记录，再确定可测环境。

<a id="q-02"></a>
### Q-02：查不到访问地区时，允许进入吗？

**场景：** 玩家打开站点，地区查询没有取得完整结果。

**问题点：** 查询失败时不能直接按一个已知国家处理，现有资料没有明确以下边界。

| 查询结果 | 需要确认 |
| --- | --- |
| 查询超时或失败 | 允许进入还是拦截？显示什么文字？ |
| 查询成功，但国家未知 | 允许进入还是拦截？显示什么文字？ |
| 国家已知，仅城市缺失 | 是否继续按国家限制判断？显示什么文字？ |

**需要确认：** 请逐行给出处理方式；如果产品站和工具站不同，请分别说明。
