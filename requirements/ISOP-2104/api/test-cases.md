### ISOP-2104-C09：核对门槛、封顶和小额派发

**前置条件：**

- 使用已经结算、能追溯配置的三组记录：未达到返利门槛；有效投注1000、比例1%、上限5；有效投注0.5、比例1%、乘积0.005。
- 后两组均已满足返利门槛。

**操作步骤：**

1. 只读核对三组记录的返利配置、有效投注和结算信息。
2. 对照各组的实际派发结果及对应账变。
3. 用已确认的派发规则核对金额，不从活动页显示反推规则。

**预期结果：**

- 未达到返利门槛：应派发0。
- 已满足门槛，有效投注1000、比例1%、上限5：应派发5。
- 已满足门槛，有效投注0.5、比例1%、乘积0.005：低于0.01，应派发0。
- 若真实记录不满足上述前置条件，不能判通过。
- 本项仅核对派发，不决定活动页应显示的金额。

**待确认：**

2032精度细节及真实样本仍需核；不依赖Q-02
