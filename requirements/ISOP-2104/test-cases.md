## 用例详情

<a id="c01"></a>
### ISOP-2104-C01：访客查看返利比例

**前置条件：**

- 已核对本次交付版本，使用未登录会话。
- 后台已配置不同游戏类型及指定游戏组的返利比例。

**操作步骤：**

1. 以访客身份打开活动页。
2. 查看表头、各项返利比例和日期切换入口。

**预期结果：**

- 表头为Category、Cashback Ratio，比例与后台配置对应，包含指定游戏比例。
- 不展示会员统计或Today切换。
- 不展示其他会员的数据。

**待确认：**

Q-01仅核交付版本/契约

<a id="c02"></a>
### ISOP-2104-C02：登录后切换今天和昨天

**前置条件：**

- 已核对本次A版交付，使用已登录会员。
- 该会员今天和昨天各有可核对金额的有效投注记录。

**操作步骤：**

1. 打开活动页，查看默认日期和统计内容。
2. 切换到Yesterday，再切回Today。
3. 对照该会员两天的有效投注记录。

**预期结果：**

- 默认显示Today。
- Category、Bet、CashBack Bonus及Total随所选日期变化，数据属于当前会员。
- 返利金额如何计算和展示，另由[C03](#c03)核对。

**待确认：**

Q-01仅核交付版本/契约

<a id="c03"></a>
### ISOP-2104-C03：查看门槛、封顶和小额返利

**前置条件：**

- 本次已交付A版。
- 使用[C09派发对账](api/test-cases.md#c09)中的三组记录：未达到门槛、触及封顶、金额低于0.01。
- 除C09的已结算记录外，还需准备Today尚未结算、Yesterday尚未派发和Yesterday已经派发的对应阶段记录或页面快照，并能核对日期、配置及已有账变；缺少某阶段证据时，该阶段保留待验证。

**操作步骤：**

1. 分别查看三组记录在活动页上的返利金额和说明文字。
2. 对照各组的统计结算阶段及C09账变记录。
3. 核对结算前后页面显示的变化。

**预期结果：**

- 页面金额及标签依Q-02，结算前后显示依Q-06，目前仍待产品确认。
- 不把“有效投注×比例”的简单乘积直接当成实际派发金额。
- C09中的已确认派发结果也不能直接替代本用例的页面显示预期。

**待确认：**

Q-01交付核验；Q-02显示金额；Q-06结算阶段

<a id="c04"></a>
### ISOP-2104-C04：展开和收起活动规则

**前置条件：**

- 后台已保存包含标题、列表和粗体的T&C规则文本。

**操作步骤：**

1. 打开活动页的T&C区域，对照后台文本。
2. 收起规则，再展开并检查内容。

**预期结果：**

- 内容来自后台配置，不使用写死的旧文本。
- 标题、列表和粗体内容与配置对应。
- 规则支持展开和收起。

<a id="c05"></a>
### ISOP-2104-C05：查看指定和默认推荐游戏

**前置条件：**

- 场景A：第一指定游戏组存在符合合规状态的游戏。
- 场景B：另一份配置完全没有指定游戏数据。

**操作步骤：**

1. 分别在两种配置下打开活动页。
2. 读取推荐游戏，对照后台的指定组或默认推荐来源。

**预期结果：**

- 场景A：推荐来自第一指定组，且游戏符合合规状态。
- 场景B：按开启的默认厂商配置，取排序前10个且符合合规状态的游戏。
- 首组停用、全部过滤及不足10项的情况另见[C08](#c08)。

**待确认：**

—

<a id="c06"></a>
### ISOP-2104-C06：滚动页面时保留底部游戏区

**前置条件：**

- 使用375px宽的移动端页面。
- T&C文本足够长，推荐区有多张游戏卡片。

**操作步骤：**

1. 滚动页面中间的内容区域，直至最后一段内容。
2. 横向滚动底部推荐游戏列表。

**预期结果：**

- 游戏图列和More Games固定在底部可见。
- 中间内容独立滚动，最后一段内容不被底部区域遮挡。

**待确认：**

—

<a id="c07"></a>
### ISOP-2104-C07：查看合计比例并进入更多游戏

**前置条件：**

- 后台配置两种不同的返利比例。

**操作步骤：**

1. 以访客身份查看B版比例表的Total行。
2. 点击活动页的More Games按钮。

**预期结果：**

- More Games的跳转目标依Q-03，目前尚未确定。
- 多种比例下Total如何展示依Q-05，目前尚未确定。
- 不自行用简单平均值作为合计比例。

**待确认：**

[Q-03](questions.md#q-03)、[Q-05](questions.md#q-05)

<a id="c08"></a>
### ISOP-2104-C08：查看推荐不足和加载失败页面

**前置条件：**

- 分别准备第一指定组停用、游戏全部过滤、可展示游戏不足10项的情形。
- 准备会员统计加载失败和推荐游戏加载失败的情形。

**操作步骤：**

1. 在每种情形下分别打开活动页。
2. 查看会员统计区和推荐区的显示内容。

**预期结果：**

- 首组停用或全部过滤后没有可展示游戏，处理方式依Q-04。
- 可展示游戏不足10项时是否补足，依Q-07。
- 会员统计或推荐游戏加载失败时的内容与重试入口，依Q-08。
- 不得误展示其他会员的统计数据；其余具体显示预期仍待上述问题答复。

**待确认：**

[Q-04](questions.md#q-04)、[Q-07](questions.md#q-07)、[Q-08](questions.md#q-08)
