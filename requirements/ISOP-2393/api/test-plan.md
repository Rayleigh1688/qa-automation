# ISOP-2393 接口测试用例草案

[需求设计](../design.md) · [契约评审](contract-review.md) · [问题与决定](../questions.md) · [功能用例](../test-cases.md)

按只读契约、受控配置写入、真实游戏准入的顺序验收。每次记录站点、版本、GMT+8 业务日和同一测试会员的脱敏关联信息。以下均为设计，状态 `NOT_RUN`。

| 编号 | 优先级 | 场景与数据 | 核心断言 | 验收点、待确认及功能用例 |
| --- | --- | --- | --- | --- |
| A01 | P0 | 会员详情查询，准备默认关闭、已开启、当日主动设置三类样本。 | 解码成功且业务读取成功。检查开关、上限、当日投注额、倒计时的类型与实际状态；锁定中的剩余秒数与 GMT+8 次日零点一致，重复读取随时间减少。 | AC-02、AC-03；Q-13；[C01](../test-cases.md#c01)、[C02](../test-cases.md#c02)、[C03](../test-cases.md#c03) |
| A02 | P0 | 后台限制状态查询，定位同站点同会员。 | 后台与会员视角的开关、当前上限一致；最后操作时间与有效操作吻合；旧通用限制状态仍可读。关闭态按确认契约清空。 | AC-06、AC-08；Q-10、Q-13；[C06](../test-cases.md#c06)、[C08](../test-cases.md#c08) |
| A03 | P0 | 专用会员第一次设置；同日再提高、降低、取消。分别准备当天有、无会员主动操作的样本，后台先改一次。 | 首次成功立即读回。当天已由会员主动设置的样本，再写被拒绝且配置、锁定状态和日志无新增变化；后台改动后，该会员仍锁定。当天仅由后台调整的会员仍可做首次主动调整。 | AC-02—AC-04；Q-11、Q-14；[C03](../test-cases.md#c03)、[C04](../test-cases.md#c04) |
| A04 | P0 | 有权限后台为当日已锁定会员设置／修改，之后取消；前后各读两侧详情。 | 改写立即生效，取消后关闭且上限清空，会员当天锁定保持原行为。对应历史各新增一笔，通用功能锁无变化。 | AC-04、AC-07、AC-08；Q-09、Q-10；[C04](../test-cases.md#c04)、[C07](../test-cases.md#c07)、[C08](../test-cases.md#c08) |
| A05 | P0 | 后台只读角色与有编辑权限角色，对同一专用会员按各自权限查询及验证写入授权。 | 两角色均能查询。只有编辑角色可写；只读角色的设置、修改与取消均被拒绝，配置和历史无变化。 | AC-08、AC-09；Q-09、Q-13；[C09](../test-cases.md#c09) |
| A06 | P1 | 用已知顺序的会员及后台操作准备至少 11 笔记录，包含首次设置、修改、取消。 | 记录按时间倒序，可核对来源、操作人、动作、前后金额、原因与操作时间；会员原因按展示规则处理。首屏 10 笔、翻页可见剩余记录，跨页无重复或遗漏。 | AC-08；Q-10；若由页面分页，分页留人工验收；[C08](../test-cases.md#c08) |
| A07 | P0 | 跨 GMT+8 23:59:59／00:00:00 测时间窗口，前日有配置与可区分的正投注额，次日预备无投注。 | 自然日变化后重新统计，原开启上限延续且会员重新获得调整资格；新一次调整立即生效并重新锁定。前日投注额不计入次日。 | AC-01、AC-03、AC-05；Q-11、Q-12；[C01](../test-cases.md#c01)、[C03](../test-cases.md#c03)、[C05](../test-cases.md#c05) |
| A08 | P0 | 上限 PHP 100.00，准备已完成日统计的金额 PHP 99.99、100.00、100.01；另备 PHP 90 真实投注加 PHP 20 Free Spin、关闭状态和已在游戏中的对照。 | 低于上限可进，等于或超过拦截，受限时无有效新游戏会话及对应新注单、扣款。Free Spin 不计入门槛；关闭状态正常进游戏，已在游戏的会话不中断。以独立已知样本和统计完成证据判定，接受需求规定的统计刷新时延。 | AC-05；Q-12、Q-13；[C05](../test-cases.md#c05)、[C10](../test-cases.md#c10) |
| A09 | P0 | Filbet 与 Filplay 各用自己站点的专用会员、登录态、限额及统计样本。只在一站触发上限，再交换站点复核。 | 配置、当日锁定、日志、统计与游戏准入各站独立。同站客户端与后台读回一致，不因另一站变更而改变。 | AC-01、AC-05；Q-12、Q-13；[C01](../test-cases.md#c01)、[C05](../test-cases.md#c05) |
| A10 | P1 | 金额试 `0`、负值、缺失、非数值、正数小额和正常两位小数；后台另试第三位小数及原因缺失、200 字、201 字。 | 无效金额或原因拒绝，配置与日志无副作用。有效边界按真实契约接收且精确读回；会员侧无额外业务最小／最大值。未定义的精度处理待确认后断言。 | AC-02、AC-07、AC-08；Q-09、Q-14；[C02](../test-cases.md#c02)、[C07](../test-cases.md#c07) |

设置和取消成功后必须读回状态与历史。只读阶段可以独立执行，配置写入阶段需要专用会员和已确认的请求契约；游戏阶段需要两站入口、日统计就绪及受控会话。拒绝分支保留业务结果与操作前后对照，样本和运行计划待环境核实后登记。
