## 用例详情

<a id="c01"></a>
### ISOP-2393-C01：Filbet与Filplay双站独立设定与GMT+8跨日边界

**前置条件：** 准备同一手机号或独立测试账号分别登录Filbet与Filplay测试环境；确认两站排期范围（Q-05）。

**操作步骤：**
1. 在Filbet设定每日投注上限（如1000 PHP），检查Filplay对应账号的每日投注上限状态。
2. 在Filplay设定不同上限（如2000 PHP）并产生投注额，核对两站各自投注额统计是否隔离。
3. 在GMT+8 23:59前与次日00:00后分别核对当日锁定状态与当日投注额重置情况。

**预期结果：** Filbet与Filplay设定、锁定状态及投注额完全独立；每日周期严格按`00:00～23:59 (GMT+8)`切换。

**待确认：** [Q-05](questions.md#q-05)。

<a id="c02"></a>
### ISOP-2393-C02：会员端初次设定每日投注上限与二次确认（H5/App）

**前置条件：** 准备未设定每日投注上限的测试会员账号；确认H5/App输入精度与文案规范（Q-01）及存量数据规则（Q-02）。

**操作步骤：**
1. 进入H5与App客户端`Responsible Gaming`页面，核对原`Daily loss limit`已改为每日投注上限。
2. 分别尝试输入0、负数、合法正数（含小数边界及大额数字），点击送出。
3. 核对二次确认弹窗提示（确认后当日无法修改或取消），点击取消后检查是否未生效；再点击确认。

**预期结果：** 小于等于0的金额被拒绝；不限制最小/最大正数上限；二次确认后立即生效，页面展示当前上限并进入当日锁定态。

**待确认：** [Q-01](questions.md#q-01)、[Q-02](questions.md#q-02)。

<a id="c03"></a>
### ISOP-2393-C03：会员当日锁定与次日修改取消规则及API校验

**前置条件：** 使用当日已完成设定或调整的测试会员账号。

**操作步骤：**
1. 当日在H5/App查看每日投注上限操作入口，确认不可修改或取消。
2. 直接调用会员端设定/修改/取消API尝试变更当日上限。
3. 在不同测试会员上于次日 GMT+8 00:00 后分别执行调高、调低及取消，再检查各会员当天能否继续修改。

**预期结果：** 当日 UI 禁止修改或取消且 API 拒绝变更；次日起调高、调低立即生效并重新锁定，取消立即关闭并清空上限。同日取消后的重设按 Q-11 确认结果验证。

**待确认：** [Q-08](questions.md#q-08)、[Q-11](questions.md#q-11)。

<a id="c04"></a>
### ISOP-2393-C04：后台调整与会员当日锁定状态互相独立校验

**前置条件：** 准备两个测试会员：账号A（当日未自行设定/调整）、账号B（当日已自行设定/调整）；准备有编辑权限的后台账号。

**操作步骤：**
1. 后台分别对账号A、账号B设定或修改每日投注上限，验证立即生效。
2. 登录账号A会员端，尝试自行修改或取消当日上限（UI与API）。
3. 登录账号B会员端，检查当日修改/取消入口及API响应。

**预期结果：** 后台调整不受会员当日锁定限制；账号A仍可自行调整一次并触发自身当日锁定；账号B仍维持锁定，不可自行修改或取消。

**待确认：** —

<a id="c05"></a>
### ISOP-2393-C05：当日投注额统计（不含Free Spin）与进游戏阻挡

**前置条件：** 准备已设定每日投注上限（如100 PHP）的测试会员；确认进游戏阻挡入口范围（Q-03）及会员日统计更新机制。

**操作步骤：**
1. 会员使用Free Spin产生投注额，待日统计更新后核对是否计入每日投注上限累计。
2. 会员正常投注使当日「会员日统计」投注额达到或超过上限（含游戏内持续投注不中断场景），确认在局中不被踢出。
3. 退出游戏后，尝试从大厅/活动/直连等入口再次进入游戏（H5、App与对应进游戏API）。
4. 次日00:00 (GMT+8)后再次尝试进入游戏。

**预期结果：** Free Spin 不计入当日投注额；已在游戏中的会员不中断；达到或超过上限后再次进入游戏被阻挡，各端文案按 Q-07 确认结果核对。次日重新计算后，低于上限时恢复正常进入。

**待确认：** [Q-03](questions.md#q-03)、[Q-07](questions.md#q-07)、[Q-12](questions.md#q-12)。

<a id="c06"></a>
### ISOP-2393-C06：后台功能限制页面「每日投注上限」区块展示

**前置条件：** 核对原型及附件截图（Q-06）；准备未设定、会员设定、后台设定三种状态的测试会员账号。

**操作步骤：**
1. 登录管理后台进入`会员管理 > 会员列表 > 会员详情 > 功能限制`。
2. 核对「每日投注上限」区块位于「功能限制总览」上方，检查各状态下的显示字段：状态、每日上限（`₱`或`-`）、设定来源（会员／后台）、最后设定时间（`YYYY-MM-DD HH:mm:ss`）、`ⓘ`提示文案与按钮组合。

**预期结果：** 任意状态可查看变更记录。有编辑权限时显示「修改」，开启状态另显示「取消」。状态、字段格式与 `ⓘ` 提示符合父单 §3。

**待确认：** [Q-06](questions.md#q-06)。

<a id="c07"></a>
### ISOP-2393-C07：后台设定、修改与取消上限弹窗校验及生效

**前置条件：** 具备「每日投注上限－编辑」权限的后台账号；确认取消上限校验细节（Q-04）。

**操作步骤：**
1. 对关闭状态会员点击「修改」。测试上限留空、0、负数、超过两位小数、原因留空和超过 200 字，再提交合法值（如 `500.50`）。
2. 对已设定会员点击「修改」：核对弹窗默认带入当前金额，提交新金额与原因。
3. 对已设定会员点击「取消上限」：测试原因留空阻挡与合法原因提交。

**预期结果：** 必填与格式校验均按预期拦截并提示；设定/修改/取消保存后立即生效，状态、金额与来源实时更新，并同步写入变更记录。

**待确认：** [Q-04](questions.md#q-04)、[Q-06](questions.md#q-06)、[Q-09](questions.md#q-09)、[Q-14](questions.md#q-14)。

<a id="c08"></a>
### ISOP-2393-C08：后台变更记录弹窗字段、排序与分页校验

**前置条件：** 准备累计产生超过10条会员与后台设定/修改/取消记录的测试会员（可覆盖未设定与已设定状态）。

**操作步骤：**
1. 在未设定与已设定状态下分别点击「变更记录」。
2. 核对表格字段（时间、来源、操作人、操作、修改前、修改后、原因），检查会员操作原因列及操作人账号显示。
3. 核对时间倒序排列及每页10笔分页切换。

**预期结果：** 会员与后台变更均完整记录；会员操作原因和取消后的金额显示 `-`，操作人显示对应会员或后台账号。按时间由新到旧，每页 10 笔。

**待确认：** [Q-06](questions.md#q-06)。

<a id="c09"></a>
### ISOP-2393-C09：后台「每日投注上限－编辑」角色权限与API鉴权

**前置条件：** 准备两个后台角色：角色1（新建或现有角色，验证默认未勾选「每日投注上限－编辑」）、角色2（已勾选该权限）。

**操作步骤：**
1. 进入`系统管理 > 角色配置`，确认「每日投注上限－编辑」独立配置且默认不勾选。
2. 分别使用角色1、角色2账号登录后台查看会员详情「每日投注上限」区块与变更记录。
3. 以只读角色会话验证专用会员的设定、修改及取消请求均被拒绝，读回状态与日志。

**预期结果：** 角色1可查看区块与变更记录但无「设定」「修改」「取消上限」按钮，且直接调用编辑API被拒绝；角色2按钮显示与API操作均正常。

**待确认：** —

<a id="c10"></a>
### ISOP-2393-C10：FilPlay H5每日投注上限UI、倒计时、标签与弹窗跳转（ISOP-2398）

**前置条件：** 确认Q-06（Figma与7张截图）、Q-07（阻挡弹窗文案）及Q-08（次日修改/移除交互）；准备FilPlay H5测试环境。

**操作步骤：**
1. 打开FilPlay H5 `Responsible Gaming`页，核对原`Daily Loss Limit`标题已改为`Daily Betting Limit`。
2. 输入金额点击保存，核对二次确认弹窗文案`After setting a Daily Betting Limit, you cannot remove it until tomorrow.`并点击确认。
3. 检查生效态展示：`Limit`、`Time remaining`自然日倒计时、`Remove`按钮置灰不可点，以及提示语`You can remove this limit from 12:00 AM <次日日期>. The limit remains active until removal is complete.`。
4. 投注达到上限后，核对`Limit`数值后是否展示`Limit Reached`标签；尝试进入游戏，核对限制弹窗文案、点击`OK`隐藏弹窗、点击`View Settings`跳转到`Responsible Gaming`设置页。
5. 次日00:00 (GMT+8)后再次进入设置页，核对上述提示语是否消失、`Remove`按钮是否恢复可点击，并点击`Remove`验证移除后投注恢复不受限制。

**预期结果：** 标题、二次确认弹窗、倒计时、提示语、`Limit Reached`标签、进游戏拦截弹窗（`OK`/`View Settings`）及次日`Remove`流程均符合最终确认的Figma与文案口径。

**待确认：** [Q-06](questions.md#q-06)、[Q-07](questions.md#q-07)、[Q-08](questions.md#q-08)。
