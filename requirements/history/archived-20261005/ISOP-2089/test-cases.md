## 用例详情

<a id="c01"></a>
### ISOP-2089-C01：默认与输入态布局及提交控件

**前置条件：**

- 按已发布视觉版本准备首页和搜索页

**操作步骤：**

1. 打开搜索页，核对placeholder；
2. 空输入时观察Search按钮；
3. 输入游戏名但不提交，核对清除（×）按钮及无即时联想

**预期结果：**

- placeholder显示Search game name；
- 未输入时Search按钮为禁用样式；
- 输入后显示清除（×）按钮；
- 输入过程中不触发搜索或即时联想；
- 默认布局包含Recommended Games和Trending Games

**待确认：**

—

<a id="c02"></a>
### ISOP-2089-C02：搜索结果与分类集合及提交触发

**前置条件：**

- 带不同分类的可搜索游戏样本

**操作步骤：**

1. 输入关键词但不点击Search、不按键盘送出；
2. 再分别点击Search和使用键盘送出，切换All Game与具体分类

**预期结果：**

- 未提交前不触发搜索；
- 点击Search或键盘送出后才显示结果；
- 结果集合按Q-02确认的匹配规则核对，分类为空时按Q-03核对；
- 不以截图示例推定算法

**待确认：**

[Q-02](questions.md#q-02)、[Q-03](questions.md#q-03)

<a id="c03"></a>
### ISOP-2089-C03：无结果展示

**前置条件：**

- 已确认不会匹配的关键词

**操作步骤：**

1. 提交搜索并查看页面

**预期结果：**

- 显示No search results found空态；
- 不保留上一轮结果

**待确认：**

—

<a id="c04"></a>
### ISOP-2089-C04：Recommended Games与Trending Games排行及进入游戏

**前置条件：**

- 准备推荐权重大于0及等于0的游戏、不同合规状态的游戏，以及Filbet Ranking的popular前5名样本

**操作步骤：**

1. 读取Recommended Games和Trending Games；
2. 核对推荐游戏横向排序、合规状态及Trending字段；
3. 分别点击游戏卡片

**预期结果：**

- Recommended Games仅展示推荐权重大于0且符合合规状态的游戏，并按权重由高到低横向排列；
- Trending Games按Filbet Ranking的popular排序展示前5名且按合规状态过滤，展示游戏图、名称、厂商名称和TOP 1–5标记；
- 两区点击后均直接进入对应游戏

**待确认：**

需核对推荐权重、Filbet Ranking数据、合规状态字段及游戏进入契约

<a id="c05"></a>
### ISOP-2089-C05：清空与空白输入

**前置条件：**

- 已有搜索结果

**操作步骤：**

1. 点击清除（×）按钮，观察输入框和页面；
2. 再尝试点击Search或键盘送出空白内容

**预期结果：**

- 输入被清空并移除清除（×）按钮；
- 空输入时Search保持禁用且不触发搜索；
- 清除后返回默认态还是保留结果仍依Q-04，未确认前不判产品FAIL

**待确认：**

[Q-04](questions.md#q-04)
