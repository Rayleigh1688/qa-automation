## 用例详情

<a id="c01"></a>
### ISOP-2233-C01：登录前后全站页脚覆盖和位置

**前置条件：** 使用登录前访客、登录后会员和已授权测试环境；确认游戏、存款、提款弹窗范围。

**操作步骤：**
1. 依导航逐页打开首页、Promos、活动页、My及其他登录前后页面。
2. 滚动到页面最底部，核对页脚与底部导航栏、浮动按钮、弹窗和Banner的相对位置。
3. 打开游戏全屏及存款/提款弹窗；依Q-01确认是否需要页脚。

**预期结果：** 页脚完整位于底部导航上方，未被遮挡或截断；覆盖范围符合最终答复，不自行补造豁免。

**待确认：** [Q-01](questions.md#q-01)、[Q-07](questions.md#q-07)。

<a id="c02"></a>
### ISOP-2233-C02：页脚ABOUT与CONTACT US文案

**前置条件：** 已取得Filbet对外客服电话、邮箱及政策页实际链接。

**操作步骤：**
1. 核对ABOUT两个链接及目标页。
2. 核对CONTACT US的固定Filbet电话、邮箱，不得显示PAGCOR邮箱。
3. 核对APP下载入口及Follow Us图标与现有入口一致。

**预期结果：** 文案、链接、电话和邮箱逐项等于最终核准值；不链接到PAGCOR邮箱。

**待确认：** [Q-02](questions.md#q-02)。

<a id="c03"></a>
### ISOP-2233-C03：页脚三个Logo和尺寸

**前置条件：**取得PAGCOR、Responsible Gaming、NPGH原始素材；准备窄手机、普通手机和宽屏。

**操作步骤：**
1. 核对页脚三个官方Logo及并排位置。
2. 测量Logo高度和两行换行情况。
3. 点击NPGH Logo确认新标签页直接打开npgh.ph。

**预期结果：** Logo高度至少40px，并排或手机宽度不足时排成两行；原文件无裁切、变形或改色，无中间页。

**待确认：** —

<a id="c04"></a>
### ISOP-2233-C04：页脚求助、排除和版权文案

**前置条件：** 已确认Need Help文案版本及Filbet牌照文案。

**操作步骤：**
1. 核对求助电话、保密声明和年份文案逐字是否一致。
2. 核对自我排除入口、公司牌照说明和Copyright文案。
3. 在窄屏核对可读性和换行。

**预期结果：** 文字与核准版本一致；自我排除链接文字与固定URL匹配；手机清晰可读。

**待确认：** [Q-04](questions.md#q-04)。

<a id="c05"></a>
### ISOP-2233-C05：固定链接新标签页直接打开

**前置条件：** 准备页脚、进站弹窗、RG页和Terms页可点击区域。

**操作步骤：**
1. 逐一点击自我排除、NPGH和在线Helpdesk链接。
2. 记录打开方式、URL和重定向次数。

**预期结果：** 每项在新标签页直接打开固定完整URL，不经过中间页或跳转。

**待确认：** —

<a id="c06"></a>
### ISOP-2233-C06：横竖宣传图白条规格和完整显示

**前置条件：**取得核准横式/竖式设计文件；确认不同Banner样本可辨认比例。

**操作步骤：**
1. 核对白条高度是否为整图20%、左右满版且无间隙。
2. 核对横幅素材的位置、三个Logo、指定文案、邮箱和核准/ASC字段。
3. 检查字体、额外文字或Logo及手机可读性。

**预期结果：** 元素依Figure 1/2排列且不重新排列；白条与页面内容符合核准文件；空字段留空。

**待确认：** [Q-04](questions.md#q-04)、[Q-08](questions.md#q-08)。

<a id="c07"></a>
### ISOP-2233-C07：宣传图适用页面和裁切检查

**前置条件：** 准备轮播、Promos、活动内页、首页弹窗及登录/注册窗口内宣传图。

**操作步骤：**
1. 在各位置打开宣传图并记录展示区比例。
2. 检查裁切、拉伸、比例及新增宣传图是否遵循规格。

**预期结果：** 所有指定位置完整显示且比例随图片原比例，不裁切、不拉伸。

**待确认：** [Q-08](questions.md#q-08)。

<a id="c08"></a>
### ISOP-2233-C08：首页弹窗24小时最多3次计数

**前置条件：** 可控制登录会员、设备列表和弹窗曝光计数；后端确认存储维度。

**操作步骤：**
1. 未登录设备在24小时内重复打开弹窗。
2. 登录会员在多个设备或重新登录后重复打开。
3. 在阈值前后核对是否第三次后停止。

**预期结果：** 未登录按设备计，登录会员按会员计；24小时内不超过3次；轮播/Promos纳入范围依Q-05确认。

**待确认：** [Q-05](questions.md#q-05)。

**待确认：** [Q-03](questions.md#q-03)。

### ISOP-2233-C14：全站禁止now字眼文案扫描

**前置条件：** 可访问主要登录前/登录后页面及现有Banner。

<a id="c15"></a>
### ISOP-2233-C15：NDRP会员登录封锁弹窗

**前置条件：** 后端已提供NDRP测试会员、未登录原因对照数据和固定客服信息。

**操作步骤：**
1. 使用NDRP会员尝试登录，记录请求和拒绝结果。
2. 核对锁头图标、标题、三段固定文案、OK按钮和客服字段。
3. 点击OK确认保持未登录；测试其他封锁原因保持原提示。

**预期结果：** NDRP只显示专用弹窗、拒绝登录且不建立会员会话；其他封锁原因沿用现有实现。

**待确认：** [Q-02](questions.md#q-02)、[Q-06](questions.md#q-06)。

<a id="c16"></a>
### ISOP-2233-C16：App是否同步调整范围核对

**前置条件：**产品确认H5与App是否共享本需求；准备对应版本。

**操作步骤：**
1. 若纳入，逐项核对H5现有RG页脚、弹窗、文案和NDRP。
2. 若排除，确认App无新改动时属于明确范围外。

**预期结果：** 最终范围与核准决定一致，不将H5测试等同为App通过。

**待确认：** [Q-07](questions.md#q-07)。

<a id="c17"></a>
### ISOP-2233-C17：宣传内容上架时段控制

**前置条件：** 明确后台发布入口、时区、运营角色和现有排期。

**操作步骤：**
1. 在17:00—20:00尝试新增或发布宣传内容。
2. 核对是否被系统拦截或运营流程阻止。
3. 核对时段前后和时区换算。

**预期结果：** 限制时段内不得新上架宣传内容；控制方式符合已确认权限和流程。

**待确认：** [Q-09](questions.md#q-09)。
