# ISOP-2190：首页GGR%分类分母设计

[设计](design.md) · [问题](questions.md) · [测试重点](test-cases.md) · [W26批次评审](../reviews/2026W26-20261006.md)

2026-10-06评审确认分类分母修复目标和首页七类范围，可准备定向回归；零投注合同见[Q-01](questions.md#q-01)。当前只有需求及原失败截图，没有修复后接口或首页实测通过证据。

## 已明确规则

- 每类GGR%采用同类分子和分母：Slot GGR% = Slot GGR / Slot `bet_amount`，Fish同理。不再共用全部游戏投注额。
- 附件24178显示首页七类：Slots、Fishing、Sports、Table、Live、Arcade、Bingo；总GGR另列。本期是**分类分母修复**，不另改GGR分子、`bet_amount`含义、其他报表或JP公式。
- 原图全平台下注17.50：Slot −4.25 / 17.50 = −24.28%，Table 10 / 17.50 = 57.14%，对应原共用分母缺陷。总GGR 5.75 / 17.50 = 32.85%是另列汇总参考；图没有各类自身下注额，不能据此算出修复后的正确分类百分比。
- 图中无GGR类别显示0.00%，但仍除以非零全平台分母，不能证明改成分类分母后的除零合同。该疑点保留在问题文件，不从旧图补造决定。
