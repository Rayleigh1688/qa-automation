## 问题详情

<a id="q-02"></a>
### Q-02：输入部分游戏名或改变大小写，能搜到吗？

**场景：** 假设有一款名为Lucky Game的游戏，玩家分别输入完整名称、Lucky或小写lucky game，再提交搜索。

**问题点：** 搜索触发方式已明确，但这些输入是否都能匹配尚未明确。

**需要确认：** 必须输入完整名称，还是输入部分名称也能搜到？大小写不同是否影响结果？以上为说明问题的示例，不是实际测试记录。

**已有答案：** 2026-09-21用户补充：提示文字为Search game name；空输入时Search按钮禁用；输入后显示清除（×）按钮；仅点击Search或键盘送出才搜索，不做即时联想。

<a id="q-03"></a>
### Q-03：选中的分类没有搜索结果，显示什么？

**场景：** 搜索结果中有游戏，但玩家切换到某个分类后，该分类没有匹配游戏。

**问题点：** 整体搜索无结果时的提示已有设计，分类内为空时是否采用同样表现尚未明确。

**需要确认：** 保留当前分类并显示No search results found，还是采用其他表现？请给出该状态的页面内容。

<a id="q-04"></a>
### Q-04：清空关键词后，回到哪个页面状态？

**场景：** 玩家已经看到搜索结果，随后点击输入框的清除（×）按钮。

**问题点：** 清除按钮及空输入的禁用状态已明确，结果区域接下来显示什么尚未明确。

**需要确认：** 返回含两组推荐游戏的默认页面，保留上一次结果，还是采用其他表现？

## 已有答案

<a id="q-01"></a>
### Q-01：两组推荐游戏按什么顺序展示？

**已确认：** Recommended Games只展示推荐权重大于0的游戏，按权重由高到低横向排列，并按合规状态过滤。Trending Games取Filbet Ranking的popular游戏排序前5名，按合规状态过滤，展示游戏图、名称、厂商名称及TOP 1–5标记。两组点击游戏均直接进入游戏。

**答复来源：** 2026-09-21用户分两次补充Trending Games和Recommended Games规则。后续仍需准备对应排名、权重和合规状态记录用于核验；业务未执行。
