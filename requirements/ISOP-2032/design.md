## 配置表单基准

1. 基础配置：返水类默认、ID32只读、名称、规则来源（后台/开发代码）、有效/失效、起止日期时间、介绍页来源（后台/前端）、全部会员/指定名单、流水场馆/游戏限制（默认所有游戏）。
2. 返利率配置：7类固定行与指定游戏覆盖行均独立设置率/上限/门槛/倍数/状态。上下限及小数精度按契约；一注只命中一规则。
3. 派发条件与弹窗：04:00、按类型分账、门槛在Step2配置、沿用Step1打码范围均为说明；只有弹窗文案可编辑。

精灵使用取消/上一步/下一步/OK。必须在真实FAT核对保存及取消后的持久化，不能拿mock的OK代替。

## 报表字段清单

- 列表：序号 / 玩家账号 / UID / 手机号 / VIP等级 / 统计日期 / 有效投注金额 / 流水返利金额 / 打码要求 / 结算时间 / 明细。
- 类型明细：游戏类型 / 有效投注额 / 返利率 / 返利金额（封顶前） / 返利上限 / 实派返利金额（已封顶标示） / 打码倍数 / 该类型打码要求。
- 按具体导出小节暂定“导出Excel”生成Xlsx，字段等于列表；概述CSV残文与操作列表达见Q-08。文件格式须真实核对，不能只看扩展名。
- 明细可点按钮或整行打开Drawer；会员摘要含账号/手机/VIP/统计日期/结算时间/实派总额，达到上限标“已封顶”。
- 活动配置：运营管理→活动列表→投注返利(ID32)→三步配置（基础配置/返利率配置/派发条件与弹窗）；后台原型保存不落地。
