# 数据库取数参考

供需求评审和只读对账使用，按实际涉及的表补充，不建立全部历史功能目录。表结构、字段注释、实测映射和业务规则分别标来源；结构存在不表示取数规则已验证。原始数据和连接配置留本机忽略目录，不写入本参考。

## 使用顺序

1. 从当前需求确定环境、字段和统计窗口；读取[核心表说明](fat-core.md)，不把FAT结论直接套入UAT或Doris。
2. 必要时运行[只读结构查询](inspect-structure.sql)，核对列、注释、主键及索引；通过现有环境配置或数据库客户端连接，不在SQL中写凭据。查询不会登录业务或修改数据库。
3. 对每个时间字段单独核实样本值单位、时区、零值和业务含义，再构造左闭右开窗口。空查询先核单位、环境、状态及实际数据范围。
4. 数据查询先限定表、字段、日期或已知记录，结合索引；大表先EXPLAIN并限制扫描，禁止为了熟悉结构使用SELECT *导出全部业务数据。元数据TABLE_ROWS是估计值，不作为业务计数。
5. 按事件→成功状态→会员/订单去重→金额与时间归属建立预期；不因字段叫first或daily就直接采用，不为追平报表随意增删过滤。
6. 记录查询日期、来源SQL、结果摘要和未验证条件。表/字段注释不自动等于最新产品规则；新需求改变口径时保留差异及来源。
