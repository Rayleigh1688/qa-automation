## TLSQ-78原始产品口径补齐（2026-09-16）

- 充值、首充、新充、复充金额均来自Completed存款订单的到账金额；提现来自Completed提现订单金额。文档“到账金额”不能直接证明实际以paid_at分日，也未直接指定amount/paid_amount字段，需对照实现。
- 首充gt=1；新充gt=1且注册日为统计日；复充gt!=1且首次充值日为统计日。多日以每日分类结果累加。复充不是所有老充值用户的再次充值；查询期包含首充日之后的后续日，也不能将后续日充值自动纳入复充。
- 评论给出统计字段：deposit_amounts、withdraw_amounts、first_deposit_amount、new_deposit_amount、new_refill_amount；人数为deposit_user_counts、first_deposit_counts、new_deposit_counts、new_refill_counts、withdraw_user_counts。它们是产品统计表字段，不假定等同于API字段或已经定位Doris表。
- 六类跨日不提供的指标统一显示--；不显示N/A。评论中的跨日去重/性能讨论未定案，正文后端要求更明确，沿用正文。
- 注充率和投充比多日应先汇总分子/分母再相除，不相加或平均每日比率；余额取结束日日末，不能累计每日余额。
- 登录人数旧评论定义为截至当日23:59:59最后登录时间在当日的用户数；保留其来源，需核对历史快照实现，不能自行改为完整登录事件去重。
- 分类：电子游戏1/2/3/5，体育4/6，电子宾果7，特殊游戏预留。
- 冲突/缺口：旧评论写总GGR为已结算net_amount合计，而昨日体育实测匹配负net_amount；两者可能涉及源字段符号约定，未核前不统一反号。旧评论还明确提出bet_amount或valid_bet_amount待确认，不能忽略该标记。较新的2022规则用于结算日归属，不凭旧文覆盖新规则。
- 前端要求还包括卡片顺序/颜色、标题与icon同行、提示hover、快捷日期位置、不可查询值--。颜色原文为#2c3e50/#3498db/#16a085；布局附件未看，不能宣称顺序/视觉全验通过。本单没有图表盈利率、分母0或舍入方式的明确答案。
