## 接口契约与实测差异

来源为api/catalog/admin/member.csv及本机接口库“后台/会员列表”相应Bruno docs段。脱敏实测摘要保存在本地忽略路径`reports/qa/member-detail/20260917/restriction-readonly.json`。

- GET /admin/member/limitation/state/info：uid定位，HTTP200/status=true，data包含member_state、manual_member_state、d。
- 实测自动状态is_risk_control/is_freeze/is_block/is_banned均false；手动prohibit_login/prohibit_deposit/prohibit_withdraw/prohibit_game均false，和页面四项允许一致。仅无锁基线验证，不能证明任一有锁拦截。
- 文档手动字段写login/deposit/withdraw/game，实际带prohibit_前缀；不可直接照文档取值。实际还出现prohibit_bonus/test/compliance_open/whitelist（当前均false），本页没有对应四项之外的开关；归属待核，不据字段名自行定义功能或报告遗漏BUG。
- 文档member_state示例有is_kyc，本轮布尔摘要未取得该字段；KYC状态仍需独立定位。
- POST /admin/member/limitation/state/update文档参数：uid、state（100封禁/101解封）、flag（10登录/11存款/12提现/13游戏）、note、code、platform_names。全部厂商为空、部分厂商英文逗号分隔。UI验证码字段与请求code映射未捕获，写接口未测。
- POST /admin/member/risk/update是risk_level、new_risk_tag、risk_tag、remark调整；与详情风控封禁表单不同，禁止仅凭名称混用。
- GET /admin/member/change/logs?change_type=2返回list/total共6条；没有向文档输出姓名/电话/操作者等原始资料。手机号/姓名历史无认证疑点仍见[basic-info.md](basic-info.md)，本轮未重测无认证非空数据。
