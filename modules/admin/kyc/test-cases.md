| ID | 场景 | 主要断言/数据前置 | 当前证据 |
| --- | --- | --- | --- |
| KYC-C01 | 列表查询/分页/空集 | 指定会员正向唯一匹配；分页计数与数据一致；已约定不命中允许null或[]且t=0；时间/渠道组合不串数据 | 菜单与字段已观察，API本轮未执行 |
| KYC-C02 | 详情与列表关联 | UID关联相同资料/状态/证件；缺失与无权限不能返回他人资料；不保存真实证件 | 列表/编辑显示已观察，独立API未执行 |
| KYC-C03 | 编辑与字段保护 | 独立干净会员；合法字段入草稿；手机号/kyc_status不变；留言可编辑；正式资料保持 | UI留言禁用，与既定规则冲突；API历史结果仅作引用 |
| KYC-C04 | 三图及字段同申请 | 合成JPG/PNG；大小边界/恢复原图/无变更；核准原子生效、驳回整笔舍弃 | 看到三图更换及前后对照入口，未上传 |
| KYC-C05 | 初次认证审核 | 各状态专用样本；通过/驳回/补件动作及审计按已核枚举；失败无禁止副作用 | 审核表单打开，动作全集和契约待补 |
| KYC-C06 | 待复核/已复核查询 | state与结果筛选、提交人/时间/姓名、计数、diff、分页 | 两页签及加载后记录已观察，无API独立对账 |
| KYC-C07 | 第二人复核 | 禁止自审、重复/并发复核；核准生效、驳回原因必填；处理后不可再次操作 | 待处理抽屉有核准/驳回；已驳回样本详情仅关闭；后端未复测 |
| KYC-C08 | 草稿冲突与客户端拦截 | 同会员仅一个待处理申请；会员新提交/补件受阻；不污染正式资料 | 待复核样本编辑按钮禁用；API及客户端未执行 |
| KYC-C09 | 异动审计 | 编辑行保留原状态，处理另增行；UID/申请关联，旧行不可改，diff与本次变更一致 | 弹窗可打开，未完整展开核对 |
| KYC-C10 | 分行联动 | 核准分行变更后门店/分行跨表及游戏限制一致；驳回保持原值 | 沿用2027 C18，当前未执行 |
| KYC-C11 | EKYC配置与自动流程 | 用户确认基本不会再开，本轮略过；仅保留开启调用三方验证、关闭仅上传的规则资产 | OUT_OF_SCOPE（2026-09-16用户决定），不是PASS |
| KYC-C12 | 权限与隐私 | 无权拒绝列表/详情/编辑/复核/证件访问；按钮与后端权限分别验证 | 仅当前已登录角色菜单观察，未换角色 |
| KYC-C13 | 重复资料提示 | 既有重复样本与普通样本对照；重复仅颜色提示，不单独引起自动驳回、禁提交/禁通过或状态变化；其他独立校验仍按各自规则；判重字段映射待核 | 用户规则已确认；颜色、接口提示字段和无额外副作用尚未实测 |

本轮无保存、审核、核准、驳回、上传、配置修改或数据库写入；未刷新远端需求。后续读写执行结果应独立记录环境/时间/样本/断言，不能直接覆盖历史结果。
