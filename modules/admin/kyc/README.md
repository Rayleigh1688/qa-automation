## 流程边界

KYC审核决定认证状态；编辑复核决定后台资料变更是否生效，二者状态独立。编辑→草稿→另一管理员核准/驳回→审计新增记录；同一会员已有待复核编辑时不得再生成第二条有效待复核申请，待处理期间会员新提交/补件也应被拦截。完整预期引用2027 AC-01—06与已确认决定。

本轮只是菜单和规则资产整理，未重跑2027专项、未变更其交付状态；无API独立执行、数据库核对或权限切换。下一步优先补列表/详情/复核查询的字段映射与只读断言，写流程沿用现有计划和专用数据，不核准历史遗留申请。

## 2026-09-16用户补充口径

- EKYC基本不会再开启，按用户决定本轮略过EKYC相关执行；KYC-C11为OUT_OF_SCOPE，不是PASS，也不阻塞人工审核、资料编辑与复核资产整理。不是认定功能已下线。
- EKYC提供玩家上传证件和人脸识别界面。三方验证开关控制是否调用三方验证接口：开启调用，关闭不调用，仅提供上传接口。关闭不等于禁止上传，也不等于自动审核通过。
- 重复资料当前仅做颜色标记，没有其他行为。不得把IP/设备/个人资料重复提示当成自动拒绝、审核拦截或状态改变依据。颜色及重复判定字段尚未独立核对，不从提示数量反推判重算法。
