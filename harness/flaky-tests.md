# Flaky Tests

## 用途

记录不稳定测试用例、触发条件和处理方式。

## 问题列表

当前没有已完成统计、可确认属于测试自身波动的 flaky 用例。

FAT 偶发 502、短信限制、支付/转账通道不可用属于环境或测试数据问题，记录在 [`known-errors.md`](known-errors.md)，不能为了提高通过率登记为 flaky 后自动重跑掩盖。

新增记录至少包含：

| 字段 | 含义 |
| --- | --- |
| 用例/命令 | 可唯一定位的测试和执行入口 |
| 首次/最近发生 | 判断是否仍活跃 |
| 失败比例 | 至少基于连续多次执行，不凭单次失败 |
| 触发条件 | 浏览器、环境、数据、并发或时序 |
| 失败证据 | 错误、trace、截图或请求摘要的本地产物路径 |
| 临时处理 | 是否允许有限重试及停止条件 |
| 根治方案 | 稳定定位、等待条件、数据隔离或产品修复 |
